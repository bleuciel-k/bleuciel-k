🚀 主なプロジェクト
Momentum — ADHD のための「着手」支援アプリ

既存の ToDo アプリ（Todoist, Things など）が 整理 に最適化されているのに対し、Momentum は ADHD の本当のボトルネックである task initiation（着手） の一点に絞ったアプリです。React Native (Expo) 製。

「今やる一つ」だけを大きく表示し、残りは隠す single-focus 設計
LLM（Claude）がタスクを「笑えるほど小さい最初の一歩」に分解
残り時間を縮む円で可視化する Time Disc、罰点・赤色を使わない shame-zero 設計
現在のエネルギー・興味にタスクを合わせるスコアリング型マッチングエンジンを自作

📂 task_system

AI TODO秘書 — AI 優先度付けタスク管理アプリ

Flutter / Firebase 製。LLM を用いてタスクの優先順位を自動で提案します。韓国語・日本語のプレゼン資料と、Overleaf 向けの LaTeX レポートも作成しました。

Chrome 拡張 AI ブラウザエージェント

ブラウザ操作を補助する AI エージェントを個人開発。「AI × 日常の生産性」というテーマを継続的に探求しています。
